# English Deep Talk Plan

英语口语主动回忆训练：目标不是“认识单词”，而是看到中文或进入真实场景后，能在 **2 秒内主动说出英文**。

## 🎤 开始学习

👉 **[点击这里打开 English Deep Talk 30 天学习网站](https://succuvivi.github.io/english-deep-talk-plan/)**

> 每天 10 个日常高频词/短语 + 场景题 + 2 秒主动回忆 + 自动复习 + Deep Talk。

## 2 秒规则

- 0–2 秒想起来 → 熟练
- 超过 2 秒 → 加入弱词池
- 完全想不起 / 用错 → 重点复习

仓库推送到 `main` 后会由现有 GitHub Pages workflow 自动部署。
