# English Deep Talk Plan

这是我的英语口语提升仓库。目标不是背会拼写，而是把**日常高频词变成聊天时能在 2 秒内主动说出来的词**，逐步从 shallow talk 走向 deep talk。

## 当前目标

- 每天学习 **10 个高频口语词**
- 不强求拼写，优先做到：**能认、能读、能想起来、能开口用**
- 每个词和一个高频搭配一起记，不孤立背词
- 优先动词、形容词和真正能推进聊天的表达
- 话题覆盖：生活、朋友、工作、关系、旅行、金钱、情绪、观点、在泰国的日常等

## 2 秒规则

看到中文意思或进入真实场景后：

- **0–2 秒想起来** → 熟练
- **超过 2 秒才想起来** → 不熟，加入 `review/weak-words.md`
- **完全想不起来 / 用错** → 重点复习

> 目标不是“我认识这个词”，而是“聊天时它能自动从嘴里出来”。

## 每日流程（约 20–30 分钟）

1. **10 个新词（8–10 分钟）**：读音 + 词性 + 中文意思 + 高频搭配 + 记忆钩子。
2. **主动回忆（5 分钟）**：只看中文/场景，2 秒内说英文。
3. **场景造句（5 分钟）**：每个词至少说一个和自己真实生活有关的短句。
4. **Deep Talk 输出（5 分钟）**：用当天至少 3 个词回答一个稍深的话题。
5. **网页小测（3–5 分钟）**：选择题 + 口语回忆，自测不熟词。

## 复习节奏

沿用：**Start → 1H → 1D → 2D → 6D**。

复习时不看拼写默写，重点做：

**中文/场景 → 英文词 → 高频搭配 → 一句话输出**

### 近期核心原则
