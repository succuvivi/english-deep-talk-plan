# English Deep Talk Plan

英语口语主动回忆训练：目标不是“认识单词”，而是看到中文或进入真实场景后，能在 **2 秒内主动说出英文**。

## 🎤 开始学习

👉 **[点击这里打开 English Deep Talk 30 天学习网站](https://succuvivi.github.io/english-deep-talk-plan/)**

> 每天 10 个日常高频词/短语 + 单词例句 + 场景题 + 2 秒主动回忆 + 自动复习 + 例句选择延展测试。

## 30 天训练升级

- 保留现有 Day 3（2026-08-12）作为基线
- 新增 Day 4–Day 33：2026-08-13 到 2026-09-11，共 30 天
- 每天 10 个日常沟通高频词/短语，共 300 个/组
- 每个词卡都有一个真实日常例句
- GitHub Pages 首页完成：学习卡、单词发音、场景选择题、2 秒回忆、到期复习、弱词池
- 第 5 部分为 **例句选择测试**：当天 10 词全部测试，并混入最多 5 道旧词/弱词延展题
- 复习按 **Start → 1H → 1D → 2D → 6D** 自动混入页面
- 训练进度和弱词保存在浏览器 localStorage

主题覆盖约时间、点餐、购物、交通、租房、工作、朋友、情绪、关系、旅行、泰国日常、钱、健康、价值观和自然日常沟通。

## 2 秒规则

- 0–2 秒想起来 → 熟练
- 超过 2 秒 → 加入弱词池
- 完全想不起 / 用错 → 重点复习

仓库推送到 `main` 后会由现有 GitHub Pages workflow 自动部署。
